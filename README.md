### Architecture & Implementations

* **Store Inventory Streaming**: Decoupled POS checkout from warehouse updates with Apache Kafka, using eventual consistency to prevent race conditions during high-volume sales.
* **Student Grouping Optimizer**: Built a Python FastAPI service running a Genetic Algorithm to place 2,338 students into 190 groups under multi-variable constraints (gender, major, quotas) with over 90% compliance, connected to a Laravel dashboard.
* **Utility & ISP Billing**: Built automated billing pipelines with cron schedulers and database transactions to calculate progressive water rates (pamdesku.com) and handle recurring ISP invoices (HNK WiFi).
* **Decoupled Community Administration**: Paired a standalone React 19 / TanStack Query frontend with a Laravel 11 REST API for neighborhood operations.
* **Digital Bookstore**: Multi-role marketplace built with Laravel and React Inertia, featuring automated Xendit payment webhooks and protected file downloads.

### Arsitektur & Implementasi

* **Store Inventory Streaming**: Memisahkan transaksi kasir dari sinkronisasi stok gudang dengan Apache Kafka, menggunakan eventual consistency untuk mencegah race condition saat transaksi tinggi.
* **Student Grouping Optimizer**: Layanan Python FastAPI berbasis Algoritma Genetika untuk mengalokasikan 2.338 mahasiswa ke 190 kelompok multi-kendala (gender, jurusan, kuota) dengan kepatuhan di atas 90%, terhubung ke dasbor Laravel.
* **Utility & ISP Billing**: Pipeline cron job terjadwal dengan transaksi atomik dan penguncian database untuk kalkulasi tarif air bertingkat (pamdesku.com) dan penagihan berkala pelanggan ISP (HNK WiFi).
* **Decoupled Community Administration**: Memadukan antarmuka mandiri React 19 dan TanStack Query dengan backend REST API Laravel 11 untuk administrasi lingkungan warga.
* **Digital Bookstore**: Marketplace produk digital berbasis Laravel dan React Inertia dengan verifikasi webhook pembayaran otomatis Xendit serta unduhan file terlindungi.
